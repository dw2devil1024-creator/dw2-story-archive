# DW2 · Story Archive

A customized SillyTavern / TauriTavern character shelf and story archive.

> Based on **砚台 · 角色书架** by 阿砚 · Codex.  
> This repository keeps the original internal storage namespace for compatibility while maintaining the customized interface as **DW2 · Story Archive**.

## 当前版本

**v1.6.0**

## 安装

在 SillyTavern / TauriTavern 的“安装扩展”中使用：

```text
https://github.com/dw2devil1024-creator/dw2-story-archive
```

分支留空，使用默认 `main`。

## 当前定制

- 首页 3:4 角色卡画廊
- 移动端三列布局
- Noto Serif SC 字体
- 独立暖色玻璃搜索栏与分页
- 暖色玻璃存档弹窗
- 固定高度存档窗口，内部列表滚动
- 卡片最近游玩时间
- 整理模式圆形选择控件
- 独立玻璃整理操作栏
- `DW2 · Story Archive` 界面品牌

## 数据兼容

内部存储 key 保持不变，仓库迁移与显示名称变化不会主动重置收藏、置顶、分类与裁切设置。
